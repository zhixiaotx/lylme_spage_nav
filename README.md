## 🛡️ 多设备防覆盖与双向增量合并 (Smart Merge)

传统书签同步在多设备使用时极易发生“手机端覆盖电脑端导致书签丢失”的问题。本项目独创 **Smart Union 双向增量并集合并算法**：

```
[设备 A (手机新增: 书签 1, 书签 2)] ────┐
                                        ├─► [Smart Union 增量合并引擎 (以 URL 唯一去重)] ─► [两端均完整保留所有书签]
[设备 B (电脑新增: 书签 3, 书签 4)] ────┘
```

- **增量自动聚合**：同时在多端添加书签后进行同步，系统自动汇聚双方新增内容，并按分类与子目录层级智能归类。
- **版本冲突保护**：若检测到云端更新时间与本地不一致，系统会弹出冲突对话框，您可以清晰比对差异并自主选择【保留双方合并】或【强制覆盖云端】。

### 【方案 A】Cloudflare Pages 零成本全球极速部署 (强烈推荐·免费首选)

> **优势**：全球 Anycast CDN 超高速访问，完全免费，自带免费 Functions 云函数与 KV / D1 数据库，是私人导航页的最佳选择！

#### 第 1 步：Fork 代码仓库
1. 注册并登录你的 [GitHub 账号](https://github.com/)。
2. 访问本项目 GitHub 仓库主页，点击右上角的 **Fork**（派生）按钮，将仓库复制到你的 GitHub 个人账号下。

#### 第 2 步：登录 Cloudflare 导入项目
1. 打开并注册/登录 [Cloudflare 控制台](https://dash.cloudflare.com/)。
2. 点击左侧菜单的 **Workers & Pages** -> 点击 **Create application**（创建应用程序）。
3. 切换到 **Pages** 选项卡 -> 点击 **Connect to Git**（连接到 Git）。
4. 授权你的 GitHub 账号，并在仓库列表中选中刚刚 Fork 的导航页仓库，点击 **Begin setup**（开始设置）。

#### 第 3 步：配置构建参数 (照着填即可)
- **Project name（项目名称）**：填入自定英文名（例如 `my-nav`，部署后网址为 `my-nav.pages.dev`）
- **Production branch（生产分支）**：`main`
- **Framework preset（框架预设）**：选择 `Vite`
- **Build command（构建命令）**：`npm run build`
- **Build output directory（构建输出目录）**：`dist`
- **Environment variables（环境变量，可选）**：
  - 若需自定义默认管理员密码，可添加变量 `VITE_SYNC_ADMIN_PASS`，值为自定义密码。

#### 第 4 步：点击部署上线
点击页面最下方的 **Save and Deploy**（保存并部署）。等待 1~2 分钟编译完成，Cloudflare 会为你生成一个可直接访问的 `xxx.pages.dev` 免费域名，点击即可畅快使用！

### 【方案 B】GitHub Pages 免服务器全自动部署

### 【方案 E】宝塔面板 / Nginx / VPS 自建部署

如果你使用的是自建服务器或宝塔面板：

1. **本地打包静态文件**：
   ```bash
   # 1. 安装项目依赖
   npm install

   # 2. 编译打包生成静态文件
   npm run build
   ```
   打包完成后，项目根目录会生成一个 `dist` 文件夹。
2. **上传静态文件**：
   将 `dist` 目录内的所有文件（包含 `index.html`、`assets` 目录等）上传到你服务器的网站根目录下（例如 `/www/wwwroot/nav.yourdomain.com`）。
3. **Nginx 配置文件参考**：
   ```nginx
   server {
       listen 80;
       server_name nav.yourdomain.com;
       root /www/wwwroot/nav.yourdomain.com;
       index index.html;

       # 支持 SPA 单页应用路径路由
       location / {
           try_files $uri $uri/ /index.html;
       }

       # 开启 Gzip 压缩，大幅提升首屏秒开速度
       gzip on;
       gzip_min_length 1k;
       gzip_types text/plain text/css application/javascript application/json image/svg+xml;
       gzip_vary on;
   }
   ```

如果你按照【方案 A】部署在 Cloudflare Pages，可以直接绑定 Cloudflare 的免费 KV 或 D1 数据库，实现全私有、超高速的免 Token 云同步！

### 1. 绑定 ONENAV_KV 键值存储 (推荐·最省心)

#### 步骤 1：创建 KV 数据库
1. 登录 Cloudflare 控制台，在左侧菜单点击 **Storage & Databases** -> **KV**。
2. 点击 **Create a namespace**（创建命名空间）。
3. 名称输入 `ONENAV_KV`（或自定义名称），点击 **Add** 创建。

#### 步骤 2：在 Pages 项目中绑定变量
1. 在左侧菜单点击 **Workers & Pages**，进入你部署好的 Pages 项目。
2. 依次点击顶部的 **Settings**（设置）-> **Functions**（函数）。
3. 向下滚动找到 **KV namespace bindings**（KV 命名空间绑定），点击 **Add binding**：
   - **Variable name（变量名称）**：必须输入 `ONENAV_KV`（或 `SPAGE_KV`）
   - **KV namespace（KV 命名空间）**：在下拉框中选择刚刚创建的 KV 数据库
4. 点击 **Save**（保存）。

#### 步骤 3：重新部署使绑定生效
进入 Pages 项目的 **Deployments**（部署）页面，找到最新的一条部署记录，点击右侧的三个点 `...` -> **Retry deployment**（重试部署）。

#### 步骤 4：在导航页中开启同步
打开你的导航站，进入 **【设置】 -> 【多云同步】**：
- 同步方案选择 **Cloudflare KV**。
- 点击 **【测试云端连接 & 立即推送】**，即刻同步成功！

## 🔄 5 大主流云同步后端配置教学

进入导航页的 **【设置】 -> 【☁️ 多云同步】**，支持以下 5 种方案：

### 1. Cloudflare KV / D1 边缘函数同步 (免配置 Token)
- **适用对象**：使用 Cloudflare Pages 部署的用户。
- **优点**：无需申请和配置任何第三方 Token，直接走边缘函数，安全高效。

---

### 2. 坚果云 / WebDAV 跨平台网盘同步 (国内首选)
- **适用对象**：国内手机、电脑多端同步（国内网络直连极速，免费网盘容量足够存放一辈子书签）。
- **保姆级配置步骤**：
  1. 注册并登录 [坚果云官网](https://www.jianguoyun.com/)。
  2. 点击右上角用户名 -> **账户信息** -> 点击 **安全选项**。
  3. 找到 **第三方应用管理**，点击 **添加应用密码**。
  4. 应用名称填写 `六零导航`，点击生成密码并**复制保存**（注意：坚果云 WebDAV 必须使用此生成的专用密码，不是网页登录密码！）。
  5. 打开导航设置中的【多云同步】，选择 **坚果云 / WebDAV**：
     - **WebDAV 服务器地址**：`https://dav.jianguoyun.com/dav/`
     - **账户邮箱**：你的坚果云注册邮箱
     - **应用密码**：步骤 4 生成的第三方应用密码
     - **同步文件名**：保持默认 `lylme_spage.json`
  6. 点击【测试云端连接 & 立即推送】即可！

---

### 3. GitHub Gist 极速同步
- **适用对象**：免建代码仓库，跨平台轻量存储。
- **配置步骤**：
  1. 打开 [GitHub Token 快捷生成页面](https://github.com/settings/tokens/new?scopes=gist&description=LyLme_Spage_Sync)。
  2. 勾选 `gist` 权限，滚动到底部点击 **Generate token**。
  3. 复制生成的以 `ghp_` 开头的 Token。
  4. 回到导航设置 -> 【多云同步】 -> 选择 **GitHub Gist**。
  5. 粘贴 Token，点击右侧的 **【自动创建并绑定新 Gist】**，系统会自动为您创建私有 Gist 并绑定完成！

---

### 4. GitHub 独立代码仓库同步 (Git 版本回溯)
- **适用对象**：希望用 Git Commit 详细追踪每一次书签增删改记录的极客用户。
- **配置步骤**：
  1. 在 GitHub 创建一个新的私人仓库（例如 `my-bookmarks`，设为 Private）。
  2. 创建一个拥有 `repo` 权限的 GitHub Personal Access Token。
  3. 在导航设置中填入你的 GitHub 用户名、仓库名、分支 `main`、文件路径 `data/lylme_spage.json` 以及 Token。
  4. 每次推送时会自动生成详细的 Git Commit 提交记录。

## ⚙️ 环境变量配置清单 (自定义密码与参数)

如果你希望在部署阶段直接自定义默认的管理员账号和密码，可在部署平台的环境变量中配置：

| 环境变量名 | 默认值 | 作用说明 |
| :--- | :--- | :--- |
| `VITE_SYNC_ADMIN_USER` | `admin` | 多云同步与后台管理的管理员用户名 |
| `VITE_SYNC_ADMIN_PASS` | `123456` | 多云同步与后台管理的管理员登录密码 |
| `VITE_EXPORT_ADMIN_USER` | `admin` | 数据备份导出鉴权的管理员用户名 |
| `VITE_EXPORT_ADMIN_PASS` | `123456` | 数据备份导出鉴权的管理员安全密码 |

### 环境变量设置方法：
- **Cloudflare Pages**：进入 Pages 项目 -> **Settings** -> **Environment variables** -> 添加变量后重试部署。
- **Vercel**：进入项目 -> **Settings** -> **Environment Variables** -> 添加变量后 Redeploy。
- **本地开发**：在根目录下新建 `.env` 文件，写入 `VITE_SYNC_ADMIN_PASS=你的密码` 即可。

```

         ↓ (若未指定或加载失败)
[网站自身域名 /favicon.ico 自动嗅探]
         ↓ (若跨域阻止或 404 缺失)
[Google 高清 Favicon 官方解析代理]
         ↓ (若处于国内特殊网络或超时)
[Icon Horse / V2EX / MyHkw 国内高可用图标镜像]
         ↓ (若全链路均无法访问)
[根据网站标题首字母自动计算哈希并生成精美双色渐变矢量徽标]
```

无论离线断网、内网私有地址还是极端网络环境，**绝不显示难看的浏览器破图小方块**！

1. **视口虚拟滚动 (Virtual Windowing)**：
   - 当单分类书签数 ≥ 60 项或总书签数 ≥ 500 项时，系统自动激活虚拟滚动引擎，只对当前屏幕可视范围内的卡片创建真实 DOM 节点。
   - 即使拥有数万个书签，DOM 节点数始终恒定在数十个，内存占用控制在 50MB 左右，流畅保持 60~120 帧满帧滑动。
2. **首屏加载呼吸动效**：
   - 针对冷启动拉取远程配置时的网络耗时，采用带有渐变光晕与顺滑旋转动效的全局 Loading 骨架屏，杜绝页面闪烁。

## 🛠️ 常见问题答疑与排错指南 (FAQ)

### Q1: 第一次使用提示“需要验证权限”，默认密码是多少？
- **回答**：默认管理员账号为 **`admin`**，默认密码为 **`123456`**。输入后点击“验证并授权”即可。如需自定义，可在环境变量中配置 `VITE_SYNC_ADMIN_PASS`。

### Q2: 为什么手机上滑动页面时，背景壁纸完全不动？
- **回答**：这是**专门优化的预期效果**！壁纸被锁定在最底层，完全消除滚动时的画面撕裂、上下移位或位移动画，带来沉浸无干扰的浏览质感。

### Q3: 为什么手机上同步后，电脑上的书签没有被覆盖消失？
- **回答**：这是本项目的**核心安全特色**！系统内置了 Smart Union 双向智能增量合并算法，多端新增的书签会自动排重汇聚，绝不会发生覆盖丢失。

### Q4: 如何单独备份某个成员的书签，或者备份部分用户的书签？
- **回答**：进入 **【设置】 -> 【👥 账户与沙箱】**：
  - **单独备份**：点击该用户卡片右下角的【单户导出】图标即可下载该用户独立 JSON。
  - **部分备份**：勾选多个用户卡片左上角的复选框，点击上方弹出的【导出所选用户备份】；或点击顶部【备份中心】进行多选批量导出。

### Q5: 怎么让朋友或家人使用我的导航站，但又不看到/修改我的私密书签？
- **回答**：管理员在【账户与沙箱】中点击【添加新用户】，为他们创建专属账号。每个账号都拥有完全物理隔离的独立沙箱空间，真正实现**一人一库，互不干扰**。

### Q6: Cloudflare Pages 部署后提示 `ONENAV_KV binding not configured`？
- **回答**：虽然创建了 KV 数据库，但未在 Pages 项目的 **Settings** -> **Functions** -> **KV namespace bindings** 中添加名为 `ONENAV_KV` 的绑定。添加绑定后，在 Deployments 页面点击 **Retry deployment**（重试部署）即可生效。

### Q7: 坚果云 WebDAV 同步提示 401 认证失败？
- **回答**：坚果云必须使用**第三方应用专属密码**，不能使用网页登录密码。请登录坚果云官网：账户信息 -> Safety/安全选项 -> 第三方应用管理 -> 添加应用密码。
